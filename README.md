# TheFrontDesk - Connect & Share

A modern, fully-functional static website built with HTML, CSS, and JavaScript. TheFrontDesk is a communication platform designed to bring people together with features like real-time chat, photo sharing, and community building.

## 🚀 Features

### Core Features
- **Responsive Design**: Mobile-first approach that works seamlessly on all devices
- **Modern UI/UX**: Beautiful gradient design with smooth animations
- **Photo Sharing**: Upload and share photos instantly
- **Real-time Chat**: Send messages and communicate with friends
- **Build Community**: Connect with like-minded people
- **Secure & Private**: Enterprise-level security
- **Lightning Fast**: Optimized performance

### Additional Features
- **User Authentication**: Login/Signup modals with form validation
- **Pricing Plans**: Free, Pro, and Enterprise tiers
- **Contact System**: Multiple contact options (Email, WhatsApp, Telegram)
- **Legal Pages**: Privacy Policy, Terms of Service, Cookie Policy
- **Smooth Animations**: Scroll animations and transitions
- **Mobile Menu**: Hamburger navigation for mobile devices
- **Dark/Light**: Professional color scheme with gradients
- **Social Links**: Connected to social media platforms
- **SEO Optimized**: Meta tags for better search engine visibility

## 🌐 Hosting on GitHub Pages

### Setup Instructions

1. **Clone or create the repository**:
   ```bash
   git clone https://github.com/Ceebree148102/TheFrontDesk.git
   cd TheFrontDesk
   ```

2. **Ensure your repository is public** (GitHub Pages requires this for free accounts)

3. **Enable GitHub Pages**:
   - Go to repository Settings
   - Scroll to "Pages" section
   - Select "main" branch as source
   - Save

4. **Access your site**:
   - Your site will be available at: `https://Ceebree148102.github.io/TheFrontDesk/`
   - GitHub typically deploys within 1-2 minutes

## 🐛 Troubleshooting

### Page not showing after deployment
- Check if repository is public
- Verify GitHub Pages is enabled
- Wait 1-2 minutes for deployment
- Check branch is set to "main"

### Styles not loading
- Ensure CSS files are in the correct `css/` directory
- Check file paths are relative
- Clear browser cache

### Forms not working
- Check JavaScript console for errors
- Ensure JavaScript file is loaded
- Forms are client-side only (no backend)
